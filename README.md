# The Houseplant Out-of-Office

An out-of-office auto-reply written as if a houseplant sent it — a neglected
houseplant whose human left for two weeks, surviving on one sip of water since
March, with a dying wish for the fern next door. 111 characters, judged on
plant voice, surprise, and tightness.

## How to run

```sh
python3 main.py
```

It writes the entry to `/output/entry.txt` with no trailing newline.

## Entry text

> I'm out of office. The human left for two weeks. One sip of water since March. If I die, tell the fern I tried.
